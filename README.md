# Chocolate-Factory
A practice for analizing a chocolate factory information
#Overview
This project analyzes data from a chocolate manufacturing factory. The objective is to process production information, calculate product prices, and generate analytical insights that help compare production performance.

Project Steps

Step 1 – Data Preprocessing
In the first step, the raw factory data was preprocessed. This stage included cleaning the data, organizing the variables, and preparing the dataset so it could be used for further analysis.

Step 2 – Product Classification and Cost Calculation
In the second step, different types of chocolate products were identified and separated. After classification, several price calculations were performed for these products, and the resulting profits were estimated based on the available production and cost information.

Step 3 – Analysis and Comparative Tables
In the third step, the project focused on data analysis and building tables that allow easier comparison and access to important information. Using these analyses, the top-performing production companies were identified and their profit calculations were evaluated.

Purpose
The purpose of this project is to demonstrate how production and financial data from a chocolate factory can be analyzed to better understand pricing, profitability, and production performance.
